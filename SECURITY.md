# Security policy

## Supported versions

Only the [latest release](https://github.com/blue-noah/git-commit-sentinel-bitbucket/releases/latest)
gets security fixes.

## Reporting a vulnerability

Please report it privately, not in a public issue: on the repository's
**Security** tab, choose **Report a vulnerability**
([direct link](https://github.com/blue-noah/git-commit-sentinel-bitbucket/security/advisories/new)).

Include the plugin and Bitbucket versions, what an attacker can do, and the
steps to reproduce it. You will get an answer within 7 days; this is a
volunteer project, so fixes come on a best-effort basis, and you will be
credited in the advisory unless you prefer otherwise.

Of particular interest: ways to get past the checks of a push, to make the
plugin reject or slow down pushes it shouldn't, or to reach a terminal, a log
or the settings form with text that isn't neutralized.
